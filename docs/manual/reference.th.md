# JSON Better Editor — คู่มืออ้างอิงการใช้งาน (ภาษาไทย)

> **สถานะ:** ตรงกับแอปเมื่อจบ Phase 2 (Text mode) วันที่ 2026-11-22
> **ลักษณะเอกสาร:** คู่มืออ้างอิง (reference) แยกตามส่วนของหน้าจอและการโต้ตอบ แล้วไล่ทีละคำสั่ง ไม่ใช่คู่มือสอนใช้งานแบบเรียบเรียง (คู่มือฉบับเรียบเรียงจะทำภายหลัง, issue #76)
> **ที่มา:** เขียนจากโค้ดจริงใน `lib/`, `macos/Runner/` และ `packages/re_editor/` ไม่ได้อิงสเปกอย่างเดียว เลข decision อ้างถึง [`docs/decision-log.md`](../decision-log.md)
> **การดูแล:** ทบทวนและแก้ไขเอกสารนี้ทุกครั้งที่จบ Phase (กฎใน `AGENTS.md`, decision #84)

## สัญลักษณ์ที่ใช้

| สัญลักษณ์ | ปุ่ม |
|---|---|
| ⌘ | Command |
| ⇧ | Shift |
| ⌥ | Option |
| ⌃ | Control |
| ⌫ | Delete (ลบถอยหลัง, ปุ่ม Delete ปกติของ Mac) |

| ↩ | Return / Enter |
| ⇥ | Tab |

สถานะของแต่ละคำสั่ง:

- **ใช้ได้** ทำงานแล้ว

- **ไม่มีผล** เป็นเมนูจากเทมเพลตของ macOS ที่แอปไม่ได้ต่อเข้ากับตัวแก้ไข

## 1. หน้าต่างแอป

### 1.1 เปิดแอป

- **ทำอะไร:** เปิดหน้าต่างเดียว ไม่มีเอกสาร ชื่อด้านบนเป็น "JSON Better Editor" และกลางหน้าต่างแสดง "Open a JSON file"
- **ขนาดหน้าต่าง:** กว้าง 60% และสูง 80% ของพื้นที่ใช้งานบนจอ (จอหลักลบแถบเมนูและ Dock) วางกลางจอ ย่อได้เล็กสุดประมาณ 20% × 20% ไม่ใช้ขนาดพิกเซลตายตัว (decision #48)
- **ไม่จำตำแหน่งเดิม:** เปิดใหม่ทุกครั้งจะกลับมาที่ขนาดและตำแหน่งข้างต้น
- **เปิดจาก Finder:** ดูข้อ [4.3](#43-เปิดไฟล์จาก-finder)

### 1.2 ย้ายและซูมหน้าต่าง

- **ย้าย:** ลากที่พื้นที่ว่างของแถบเครื่องมือ (แถวเดียวกับปุ่มแดง เหลือง เขียว) ลากบนปุ่มจะไม่ย้ายหน้าต่าง
- **ดับเบิลคลิกพื้นที่ว่างของแถบเครื่องมือ:** ทำตามที่ตั้งไว้ใน System Settings › Desktop & Dock ("Double-click a window's title bar to"): Zoom (ค่าปกติ), Minimize หรือไม่ทำอะไร
- **ปุ่มเขียว / Window › Zoom / View › Enter Full Screen (⌃⌘F):** พฤติกรรมมาตรฐานของ macOS

### 1.3 ชื่อเอกสารและเครื่องหมายแก้ไข

- ใต้แถบเครื่องมือมีชื่อเอกสาร: ชื่อไฟล์ (เช่น `data.json`) หรือ `Untitled` สำหรับเอกสารใหม่ที่ยังไม่บันทึก ชื่อยาวจะถูกตัดด้วย "…"
- เมื่อมีการแก้ไขที่ยังไม่บันทึก ชื่อจะเป็น `data.json — Edited` และปุ่มปิด (สีแดง) จะมีจุดอยู่ข้างใน (decision #55)
- Undo จนกลับไปตรงกับที่บันทึกไว้ เครื่องหมาย Edited จะหายไป แต่การพิมพ์แก้กลับเองให้ตรงกับของเดิมจะยังแสดง Edited อยู่ (ดู [ข้อจำกัด](#16-ข้อจำกัดที่ทราบ))
- พับหรือคลี่บล็อกไม่นับเป็นการแก้ไข

### 1.4 ปิดหน้าต่างและออกจากแอป

| การกระทำ | วิธีเรียก | ผล |
|---|---|---|
| ปิดหน้าต่าง | ปุ่มแดง, File › Close, ⌘W | ถ้ามีการแก้ไขค้าง จะถามก่อน ([4.7](#47-กล่องถามเมื่อมีการแก้ไขที่ยังไม่บันทึก)) ปิดหน้าต่างเดียวแล้วแอปจะออกเลย (decision #68) |
| ออกจากแอป | JSON Better Editor › Quit, ⌘Q | ถ้ามีการแก้ไขค้าง จะถามก่อน ถ้าเลือก Cancel แอปไม่ออก |

### 1.5 ธีม (สว่าง / มืด)

- ตามการตั้งค่าของ macOS อัตโนมัติ (System Settings › Appearance) เปลี่ยนแล้วมีผลทันที
- สีเป็นแบบพื้นฐาน ธีม One Light / One Dark จะมาใน Phase 4 ปุ่ม Theme บนแถบเครื่องมือยังไม่ทำงาน

### 1.6 ภาษา

- หน้าจอเป็นภาษาอังกฤษอย่างเดียวในตอนนี้ ภาษาไทยและปุ่มสลับภาษามาใน Phase 4

### 1.7 หนึ่งหน้าต่างหนึ่งเอกสาร

- แต่ละหน้าต่างมีเอกสารเดียว New หรือ Open จะแทนที่เอกสารในหน้าต่างนั้น (หลังถามเรื่องการแก้ไขที่ค้าง)
- ต้องการเปิดหลายไฟล์พร้อมกัน ให้เปิดแอปหลายอินสแตนซ์ (decision #67)

## 4. การจัดการไฟล์

### 4.1 New — สร้างเอกสารใหม่

- **เรียกใช้:** File › New, ⌘N, ปุ่ม New บนแถบเครื่องมือ
- **ผล:** ถ้าเอกสารเดิมมีการแก้ไขค้าง จะถามก่อน ([4.7](#47-กล่องถามเมื่อมีการแก้ไขที่ยังไม่บันทึก)) แล้วแทนที่ด้วยเอกสารใหม่ชื่อ `Untitled` ที่มีเนื้อหา `{}` เคอร์เซอร์อยู่ใน Text pane พร้อมพิมพ์
- **หมายเหตุ:** ประวัติ Undo เริ่มใหม่ ช่องค้นหาที่เปิดอยู่ยังเปิดค้างไว้

### 4.2 Open — เปิดไฟล์

- **เรียกใช้:** File › Open…, ⌘O, ปุ่ม Open บนแถบเครื่องมือ
- **ผล:** ถามเรื่องการแก้ไขค้างก่อน (ถ้ามี) แล้วแสดงหน้าต่างเลือกไฟล์ (sheet ติดกับหน้าต่าง) เลือกได้เฉพาะไฟล์ `.json` ทีละไฟล์ เลือก Cancel จะไม่มีอะไรเปลี่ยน
- **เมื่อเปิดสำเร็จ:** แสดงข้อความในไฟล์ตามที่เป็น (ไม่จัดรูปแบบใหม่) ชื่อเอกสารเป็นชื่อไฟล์ ประวัติ Undo เริ่มใหม่
- **กรณีผิดพลาด:**

| สถานการณ์ | หัวข้อกล่อง | ข้อความ |
|---|---|---|
| JSON ไม่ถูกต้อง | Can't open ‹ไฟล์› | `Line ‹บรรทัด›, column ‹คอลัมน์›: ‹สาเหตุ›` ไฟล์จะไม่ถูกเปิด เอกสารเดิมยังอยู่ในหน้าต่างพร้อมการแก้ไข แม้จะตอบ Don't Save ไปแล้ว |
| ไฟล์ไม่ใช่ข้อความ UTF-8 | Can't open ‹ไฟล์› | The file is not UTF-8 text. |
| อ่านไฟล์ไม่ได้ (สิทธิ์ ฯลฯ) | Can't open ‹ไฟล์› | ข้อความจากระบบ |
| หน้าต่างเลือกไฟล์ผิดพลาด | Can't open the file | ข้อความจากระบบ |

- **รายละเอียดการตรวจ JSON:** ตามมาตรฐาน RFC 8259 รับ BOM ต้นไฟล์ได้ คีย์ซ้ำเก็บไว้ทั้งหมดตามลำดับ ซ้อนได้ลึกสุด 512 ชั้น
- กล่องข้อผิดพลาดมีปุ่ม OK กด ↩ เพื่อปิดได้

### 4.3 เปิดไฟล์จาก Finder

- **เรียกใช้:** คลิกขวาไฟล์ `.json` › Open With › JSON Better Editor หรือดับเบิลคลิกถ้าตั้งแอปเป็นค่าเริ่มต้นของ `.json` แล้ว (แอปไม่ยึดเป็นค่าเริ่มต้นเองตอนติดตั้ง, decision #69)
- **ถ้าแอปยังไม่เปิด:** แอปเปิดแล้วโหลดไฟล์นั้นทันที
- **ถ้าแอปเปิดอยู่:** ไฟล์ใหม่แทนที่เอกสารในหน้าต่าง หลังถามเรื่องการแก้ไขค้าง (decision #56)
- **ถ้ามีกล่องโต้ตอบเปิดอยู่:** ไฟล์จะรอจนกล่องปิดก่อน
- **เลือกหลายไฟล์พร้อมกัน:** เปิดเฉพาะไฟล์สุดท้าย
- ข้อผิดพลาดเหมือน [4.2](#42-open--เปิดไฟล์)

### 4.4 Save — บันทึก

- **เรียกใช้:** File › Save, ⌘S
- **เอกสารที่มีไฟล์แล้ว:** เขียนทับไฟล์เดิม
- **เอกสารใหม่ (Untitled):** ทำงานเหมือน Save As (decision #43)
- **สิ่งที่ถูกเขียนลงไฟล์:** JSON ที่จัดรูปแบบใหม่ เยื้อง 2 ช่องว่าง ลงท้ายด้วยขึ้นบรรทัดใหม่ (decisions #28, #47) ตัวเลขเขียนตามที่พิมพ์ไว้ (`1.0` ยังเป็น `1.0`)
- **ข้อความใน Text pane ไม่เปลี่ยน:** แอปเก็บข้อความตามที่พิมพ์ไว้ ไม่จัดรูปแบบในตัวแก้ไข ไฟล์บนดิสก์จึงอาจหน้าตาต่างจากที่เห็นบนจอ (decision #61) หลังบันทึก เครื่องหมาย Edited หายไป
- **JSON ไม่ถูกต้อง:** ไม่บันทึก แสดงกล่อง "Can't save ‹ไฟล์›" พร้อมบรรทัดและคอลัมน์ที่ผิด (decision #54)
- **เขียนไม่สำเร็จ:** แสดงกล่อง "Can't save ‹ไฟล์›" พร้อมข้อความจากระบบ และพยายามคืนเนื้อหาเดิมของไฟล์
- กดซ้ำระหว่างที่ Open / Save / Save As ยังทำงานอยู่จะถูกข้าม

### 4.5 Save As — บันทึกเป็น

- **เรียกใช้:** File › Save As…, ⇧⌘S
- **ผล:** แสดงหน้าต่างบันทึก (sheet) ชื่อเริ่มต้นคือชื่อไฟล์ปัจจุบันหรือ `Untitled` ประเภทไฟล์ `.json` Cancel แล้วไม่มีอะไรเปลี่ยน
- **เมื่อสำเร็จ:** เอกสารผูกกับไฟล์ใหม่ ชื่อเอกสารเปลี่ยนเป็นชื่อไฟล์ใหม่ การเขียนและข้อผิดพลาดเหมือน [4.4](#44-save--บันทึก)

### 4.6 Close

ดู [1.4](#14-ปิดหน้าต่างและออกจากแอป)

### 4.7 กล่องถามเมื่อมีการแก้ไขที่ยังไม่บันทึก

- **ขึ้นเมื่อ:** New, Open, เปิดจาก Finder, ปิดหน้าต่าง หรือออกจากแอป ขณะที่เอกสารมีเครื่องหมาย Edited
- **หัวข้อ:** Do you want to save the changes made to "‹ไฟล์›"?
- **ข้อความ:** Your changes will be lost if you don't save them.

| ปุ่ม | ผล |
|---|---|
| Save (ปุ่มหลัก, กด ↩) | บันทึกก่อน (เอกสารใหม่จะขึ้นหน้าต่าง Save As) ถ้าบันทึกไม่สำเร็จหรือกด Cancel ในหน้าต่างบันทึก คำสั่งเดิมจะถูกยกเลิก |
| Don't Save | ทิ้งการแก้ไข แล้วทำคำสั่งเดิมต่อ |

- ระหว่างที่กล่องใด ๆ ของแอปเปิดอยู่ เมนูและคีย์ลัดของ File, Edit, View จะไม่ส่งผลกับเอกสารด้านหลัง (#54)

## 5. Text pane: การแสดงผล

### 5.1 ฟอนต์และพื้นที่

- ฟอนต์ Menlo 13 pt (สำรอง Monaco, Courier)
- บรรทัดที่เคอร์เซอร์อยู่มีพื้นหลังจาง ๆ

### 5.2 สีของ JSON (Syntax highlighting)

| ส่วน | สีในโหมดสว่าง | สีในโหมดมืด |
|---|---|---|
| คีย์ (สตริงที่ตามด้วย `:`) | ม่วง | ม่วงอ่อน |
| สตริง | เขียว | เขียวอ่อน |
| ตัวเลข | น้ำเงิน | ฟ้า |
| `true` / `false` | ส้ม | ส้มอ่อน |
| `null` | แดง | แดงอ่อน |
| `{ } [ ] , :` | สีข้อความรอง | สีข้อความรอง |

- JSON ที่ไม่ถูกต้องระหว่างพิมพ์ยังมีสีอยู่ สตริงที่ยังไม่ปิดเครื่องหมายคำพูดจะเป็นสีเขียวไปจนสุดบรรทัด (decision #70)
- มีสีสำหรับไฟล์ขนาดถึง 64 MB

### 5.3 เลขบรรทัด

- อยู่ในแถบซ้าย (gutter) กว้างขึ้นตามจำนวนบรรทัด เลขของบรรทัดที่เคอร์เซอร์อยู่เป็นสีเต็ม บรรทัดอื่นสีจาง
- เมื่อเปิด Word Wrap เลขบรรทัดยังนับบรรทัดจริง ไม่นับบรรทัดที่ตัดขึ้นใหม่

### 5.4 จับคู่วงเล็บและเครื่องหมายคำพูด

- **เคอร์เซอร์อยู่ในสตริง:** เครื่องหมายคำพูดเปิดและปิดของสตริงนั้นมีกรอบ
- **เคอร์เซอร์อยู่ติดวงเล็บ `{ } [ ]`:** วงเล็บนั้นและคู่ของมันมีกรอบ ดูวงเล็บก่อนเคอร์เซอร์ก่อน ถ้าไม่มีจึงดูวงเล็บหลังเคอร์เซอร์
- **ไม่แสดงเมื่อ:** มีการเลือกข้อความอยู่, สตริงยังไม่ปิด, วงเล็บไม่ครบคู่ หรือคู่ไม่ตรงชนิด (`[` ปิดด้วย `}`) วงเล็บในสตริงไม่ถูกนับ (decision #71)

## 6. Text pane: การพิมพ์และแก้ไข

Text pane รับคีย์บอร์ดทันทีหลัง New หรือ Open (decision #64)

### 6.1 พิมพ์ข้อความ

- พิมพ์ได้ตามปกติ รวมถึงการพิมพ์ภาษาไทยหรือภาษาที่ใช้ IME
- **ไม่ปิดวงเล็บหรือเครื่องหมายคำพูดให้อัตโนมัติ** (decision #65)

### 6.2 ขึ้นบรรทัดใหม่ — ↩

- **คีย์:** ↩ (รวมถึง ⇧↩, ⌘↩, ⇧⌘↩ และ Enter บนแป้นตัวเลข ให้ผลเหมือนกัน)
- บรรทัดใหม่ได้ระยะเยื้องเท่ากับบรรทัดบน
- ถ้าเคอร์เซอร์อยู่ระหว่างวงเล็บคู่ เช่น `{|}` จะแยกเป็นสามบรรทัด บรรทัดกลางเยื้องเพิ่ม 2 ช่อง และวงเล็บปิดอยู่บรรทัดล่าง
- ถ้ารายการคำแนะนำคีย์เปิดอยู่ ↩ จะเลือกคำแนะนำแทน ([12](#12-คำแนะนำชื่อคีย์-key-autocomplete))

### 6.3 เยื้อง — ⇥ (Tab)

- **ไม่มีการเลือก หรือเลือกบางส่วนในบรรทัดเดียว:** แทนที่ส่วนที่เลือกด้วยช่องว่างจนถึงจุดเยื้องถัดไป (ทุก 2 ช่อง)
- **เลือกเต็มบรรทัด หรือหลายบรรทัด:** เพิ่ม 2 ช่องหน้าทุกบรรทัดที่เลือก (#37)
- ไม่ใส่ตัวอักษร Tab ใช้ช่องว่างเสมอ (decision #57)

### 6.4 ลดเยื้อง — ⇧⇥

- ลดระยะเยื้องหนึ่งระดับ (2 ช่อง) ของบรรทัดที่เคอร์เซอร์อยู่ หรือทุกบรรทัดที่เลือก บรรทัดที่ไม่มีช่องว่างนำหน้าไม่เปลี่ยน ถ้าการเลือกหลายบรรทัดจบที่ต้นบรรทัดสุดท้าย บรรทัดนั้นไม่ถูกลดเยื้อง

### 6.5 ลบ

| คีย์ | ผล |
|---|---|
| ⌫ (หรือ ⇧⌫) | ลบตัวอักษรก่อนเคอร์เซอร์ หรือลบส่วนที่เลือก |
| ⌦ (หรือ ⇧⌦) | ลบตัวอักษรหลังเคอร์เซอร์ หรือลบส่วนที่เลือก |
| ⌥⌫ (หรือ ⌥⇧⌫, ⇧⌘⌫) | ลบถอยหลังถึงต้นคำ |
| ⌥⌦ (หรือ ⌥⇧⌦, ⇧⌘⌦) | ลบไปข้างหน้าถึงท้ายคำ |
| ⌘⌫ | ลบตั้งแต่เคอร์เซอร์ถึงต้นบรรทัด ถ้าอยู่ต้นบรรทัดแล้วจะรวมกับบรรทัดบน |
| ⌘⌦ | ลบตั้งแต่เคอร์เซอร์ถึงท้ายบรรทัด ถ้าอยู่ท้ายบรรทัดแล้วจะรวมบรรทัดล่างขึ้นมา |
| ⌘D | ลบทั้งบรรทัด (หรือทุกบรรทัดที่เลือก) |

### 6.6 คำสั่งระดับบรรทัด

| คีย์ | ผล |
|---|---|
| ⌥↑ | ย้ายบรรทัดปัจจุบัน (หรือบรรทัดที่เลือก) ขึ้นหนึ่งบรรทัด |
| ⌥↓ | ย้ายลงหนึ่งบรรทัด |
| ⌘L | เลือกบรรทัดเต็มบรรทัด (ทุกบรรทัดที่การเลือกครอบอยู่) |
| ⌃T | สลับตัวอักษรสองตัวรอบเคอร์เซอร์ |

### 6.7 คีย์ที่ปิดไว้ใน Text pane

- ⌘/ และ ⇧⌘/ (ใส่คอมเมนต์) ปิดไว้ เพราะ JSON ไม่มีคอมเมนต์

## 9. Undo / Redo

| คำสั่ง | คีย์ / เมนู | ผล |

| Undo | ⌘Z, Edit › Undo | ย้อนการแก้ข้อความล่าสุด |

- **หนึ่งขั้นคืออะไร:** การพิมพ์ต่อเนื่องรวมเป็นหนึ่งขั้น ส่วน Cut, Paste, Tab/⇧Tab, ย้ายบรรทัด, ลบบรรทัด เป็นขั้นละครั้ง

## 10. การพับบล็อก (Folding)

- **พับได้:** ทุก `{ }` หรือ `[ ]` ที่กินพื้นที่มากกว่าหนึ่งบรรทัด
- **เครื่องหมายในแถบซ้าย:** ▼ บล็อกเปิดอยู่, ▶ บล็อกพับอยู่ (แสดงเฉพาะบรรทัดที่เปิดบล็อก)
- **พับ / คลี่:** คลิกที่ ▼ หรือ ▶
- **บล็อกที่พับ:** เหลือหนึ่งบรรทัด ลงท้ายด้วย `⋯` ถ้าบรรทัดปิดมีแค่ `}` หรือ `]` (และ `,`) บรรทัดปิดจะถูกพับไปด้วย (decision #72)
- **การพับไม่ใช่การแก้ไข:** ไม่ทำให้เกิด Edited ไม่ถูกบันทึกลงไฟล์ และไม่จำไว้เมื่อเปิดไฟล์ใหม่
- **การค้นหาคลี่ทุกบล็อก:** พิมพ์คำค้นแล้วทุกบล็อกที่พับอยู่จะถูกคลี่ออก ([13.2](#132-พิมพ์คำค้น))
- ยังไม่มีคีย์ลัดหรือเมนูสำหรับพับ / คลี่ทั้งหมด

## 12. คำแนะนำชื่อคีย์ (Key autocomplete)

### 12.1 รายการขึ้นเมื่อไร

- พิมพ์ `"` ในตำแหน่งที่เป็นคีย์ของ object: หลัง `{`, หลัง `,` หรือที่ต้นบรรทัด และต้องอยู่ใน object ไม่ใช่ใน array
- รายการแสดงคีย์ทุกตัวที่มีอยู่แล้วในเอกสาร (รวมในบล็อกที่พับอยู่) ที่ขึ้นต้นด้วยสิ่งที่พิมพ์หลัง `"` แบบตรงตัวพิมพ์เล็กใหญ่ เรียงตามตัวอักษร A–Z ไม่แสดงคีย์ที่ตรงกับที่พิมพ์ทุกตัวอักษรแล้ว
- พิมพ์ต่อแล้วรายการกรองตามไปเรื่อย ๆ ไม่มีคีย์ที่ตรงเลย รายการจะปิด
- รายการแสดงสูงสุด 8 แถวต่อครั้ง เลื่อนดูได้ (decision #75)

### 12.2 คีย์ขณะรายการเปิดอยู่

| คีย์ / เมาส์ | ผล |
|---|---|
| ↑ / ↓ | เลื่อนตัวเลือก |
| ↩ | ใส่คีย์ที่เลือก พร้อมเครื่องหมายคำพูดปิด (ถ้ายังไม่มี) ไม่ใส่ `:` ให้ |
| คลิกที่รายการ | เหมือน ↩ |
| ⇥ | เยื้องตามปกติ รายการยังเปิดอยู่ |
| Esc | ปิดรายการ |

## 13. การค้นหา (Search)

ช่องค้นหาอยู่ระหว่างชื่อเอกสารกับ Text pane (decision #76)

### 13.1 เปิดช่องค้นหา

- **เรียกใช้:** ปุ่ม Search บนแถบเครื่องมือ, ⌘F, Edit › Find › Find…
- ถ้ายังไม่มีเอกสาร ไม่มีผล
- ถ้าช่องค้นหาเปิดอยู่แล้ว คีย์บอร์ดจะกลับไปที่ช่องค้นหาและเลือกคำค้นเดิมทั้งหมด พร้อมพิมพ์ทับ

### 13.2 พิมพ์คำค้น

- ค้นทุกครั้งที่พิมพ์ แล้วเลือกผลแรกของเอกสาร (ไม่ใช่ผลแรกหลังเคอร์เซอร์) เลื่อนจอไปให้เห็น
- **ค้นที่ไหน:** ข้อความในคีย์และค่าสตริง (ระหว่างเครื่องหมายคำพูด), ตัวเลข, `true`, `false`, `null` **ไม่ค้น** ในเครื่องหมายวรรคตอน (`{ } [ ] , :` และเครื่องหมายคำพูด) หรือช่องว่างระหว่าง token ผลหนึ่งรายการไม่ข้ามสอง token
- **ไม่สนตัวพิมพ์เล็กใหญ่**, เป็นข้อความธรรมดา ไม่มี regex
- **คลี่บล็อกที่พับ:** ทุกบล็อกที่พับอยู่จะถูกคลี่เพื่อให้เห็นผลที่อยู่ข้างใน
- **ตัวนับ:** แสดง "2 of 7" (ผลที่เลือก / ทั้งหมด), "No results" เมื่อไม่พบ (การเลือกในเอกสารไม่เปลี่ยน), ว่างเมื่อไม่มีคำค้น

### 13.3 ไปผลถัดไป / ก่อนหน้า

| วิธีเรียก | ผล |
|---|---|
| ↩ ในช่องค้นหา, ⌘G, Edit › Find › Find Next, ปุ่ม ˅ | ผลถัดไปหลังการเลือกปัจจุบัน |
| ⇧↩ ในช่องค้นหา, ⇧⌘G, Edit › Find › Find Previous, ปุ่ม ˄ | ผลก่อนหน้า |

- นับจากตำแหน่งที่เลือกอยู่ในเอกสาร ถ้าย้ายเคอร์เซอร์เองแล้วกด ⌘G จะไปผลถัดจากเคอร์เซอร์
- **วนรอบ:** ผลสุดท้ายไปต่อคือผลแรก ผลแรกย้อนกลับคือผลสุดท้าย (#42)
- ค้นใหม่ทุกครั้งที่กด จึงรวมการแก้ไขที่เพิ่งทำด้วย
- ⌘G / ⇧⌘G ขณะช่องค้นหาปิดอยู่ จะเปิดช่องค้นหาแทน (ยังไม่กระโดด)
- ปุ่ม ˄ ˅ เป็นสีเทาเมื่อไม่มีผล

### 13.4 ปิดช่องค้นหา

- **เรียกใช้:** Esc ในช่องค้นหา หรือปุ่ม × ด้านขวา
- **ผล:** ช่องค้นหาปิด ผลที่เลือกยังถูกเลือกค้างไว้ในเอกสาร คีย์บอร์ดกลับไปที่ Text pane
- เปิดใหม่ช่องค้นหาจะว่าง

### 13.5 ที่ยังไม่มี

- แทนที่ (Replace), ตัวเลือกตรงตัวพิมพ์, regex, ไฮไลต์ผลทั้งหมดพร้อมกัน, ค้นใน Node pane (Phase 3)

## 16. ข้อจำกัดที่ทราบ

- **เครื่องหมาย Edited ค้าง:** ถ้าพิมพ์แก้จนข้อความกลับไปเหมือนที่บันทึกไว้เอง (ไม่ใช่ Undo) จะยังแสดง Edited อยู่จนกว่าจะ Undo หรือ Save (decision #79)
- **คำแนะนำคีย์ช้าไปเล็กน้อย:** รายการคีย์ของเอกสารถูกเก็บไว้ใช้ซ้ำ 2 วินาที คีย์ที่เพิ่งเพิ่มที่อื่นในเอกสารภายใน 2 วินาทีอาจยังไม่ขึ้น (decision #79)
- **คำแนะนำคีย์ครั้งแรกในไฟล์ใหญ่:** ครั้งแรกอาจช้าในไฟล์ระดับหลาย MB (issue #67 ยังเปิดอยู่)
- **ขนาดไฟล์:** ไฟล์ถึงประมาณ 30 MB เปิดได้ภายใน 2.5 วินาที ไฟล์ 5 MB ประมาณ 0.5 วินาที (`docs/performance.md`)
- **ไฟล์ที่บันทึกถูกจัดรูปแบบใหม่เสมอ:** ไม่มีตัวเลือกให้เก็บรูปแบบเดิม (decision #28)
- **การเขียนไฟล์ไม่ใช่แบบ atomic:** ถ้าเครื่องดับระหว่างบันทึก ไฟล์อาจเสียได้ (decision #42)
